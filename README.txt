PROJECT REVIEW — README
=======================

Included HTML projects
----------------------
1. project 1.html — My Personal Portfolio
   A personal portfolio with Home, About, Education, Skills, Projects, Achievements, Resume, and Contact sections.

2. project 2.html — Sweet Treats Bakery
   A bakery landing page with navigation, product cards and prices, a special offer, emoji gallery, About section, and contact information.

3. project 5.html — Student Academic Dashboard
   A student dashboard with academic summary cards, marks table, progress bars, announcements, student information, and an examination schedule.

How to run
----------
1. Keep each .html file in a folder on your computer.
2. Double-click the HTML file, or right-click it and choose Open with a web browser.
3. The projects use embedded/internal CSS, so no CSS installation is required.
4. The dashboard also uses a small embedded JavaScript block for the current date and the View Student Details toggle.

Technologies
------------
- HTML5 for page structure and sections.
- Internal CSS for colors, layout, cards, hover effects, responsive rules, and animations.
- JavaScript in the Student Academic Dashboard for the displayed date and profile toggle.

Review notes
------------
- Portfolio: the Resume button points to resume.pdf. That PDF is not included in the supplied files, so add the correct resume.pdf beside the HTML file for the download to work. There appears to be a stray backtick immediately after the Resume comment; remove it if it appears as unwanted text.
- Bakery: the page is a static showcase. The contact details and product prices are sample content as written in the source; update them before publishing. There is no order/cart form or backend.
- Dashboard: marks, attendance, student details, and exam dates are hard-coded demonstration data. The View Student Details button toggles a profile snippet, and Print Dashboard invokes the browser print dialog. No database or login is implemented.
- All three projects have responsive CSS rules. Test them on mobile widths before submission.
